# FORMIST GYM 会員マイページ

LINE公式アカウントから開く、会員さん専用の記録ページです。

- **会員さん**：今日のメニュー／体重・体脂肪率のグラフ／コースの進み具合／トレーナーからのひとこと を見られます（自分の記録だけ）
- **トレーナー**：全員分の記録を入力・編集できます（LINE上の同じページから）

## まずは見た目を確認（デモ）

`config.js` が空のあいだは、サンプルデータの **デモ表示** になります。
`mypage/index.html` をブラウザで開くと、画面上部で「会員／トレーナー／未登録」の見え方を切り替えられます。
デモで入力した内容はページを閉じると消えます。

## しくみ

```
LINE（リッチメニュー）
   └─ マイページ（LIFF：mypage/）  ── LINEのIDトークン ──▶  Google Apps Script（gas/Code.gs）
                                                                  ├─ LINEのサーバーで本人確認
                                                                  └─ Googleスプレッドシートに保存
```

- 誰の記録を返すかは**サーバー側**で、LINEで確認できた本人のIDから決めます。会員さんがURLや通信を書き換えても、他の人の記録は見られません。
- トレーナーかどうかは、スプレッドシートの「Trainers」シートに登録されているかで決まります。
- データはスプレッドシートにあるので、シートを直接見たり直したりもできます。スプレッドシートは**誰とも共有しない**でください。

## 本番の設定手順（30分ほど）

### 1. スプレッドシートとサーバー（Google Apps Script）

1. Googleドライブで新しいスプレッドシートを作る（名前は「FORMIST 会員記録」など）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身を全部消し、`mypage/gas/Code.gs` の中身を貼り付けて保存
4. 上の関数選択で `setup` を選んで **実行**（初回は権限の確認が出るので許可）
   → スプレッドシートに Members / Trainers / Pending / Menus / Body / Messages / Milestones のシートができます

### 2. LINE Developers で LIFF アプリを作る

1. [LINE Developers](https://developers.line.biz/console/) にログインし、LINE公式アカウントと**同じプロバイダー**を開く
2. 「新規チャネル作成」→ **LINEログイン** を作成（アプリタイプは「ウェブアプリ」）
3. 作ったチャネルの「チャネル基本設定」にある **チャネルID** をメモ
4. 「LIFF」タブ → 追加
   - サイズ：**Full**
   - エンドポイントURL：マイページを公開するURL（例：`https://（LPのドメイン）/mypage/`）
   - Scope：**openid** と **profile** にチェック
   - 友だち追加オプション：On (Aggressive)（任意。公式アカウントの友だち追加をうながせます）
5. 表示された **LIFF ID** をメモ
6. チャネルを **公開済み** にする（開発中のままだと、登録したテスターしか開けません）

### 3. サーバーを公開する

1. Apps Script の左メニュー **プロジェクトの設定 → スクリプト プロパティ** に追加
   - プロパティ：`LINE_CHANNEL_ID`　値：手順2-3のチャネルID
2. 右上の **デプロイ → 新しいデプロイ** → 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
3. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をメモ

「全員」にしても、LINEで本人確認できないリクエストはすべて断るので大丈夫です。

### 4. マイページに設定を入れて公開

`mypage/config.js` に値を入れて、LPと同じ場所に公開します。

```js
window.FORMIST_CONFIG = {
  LIFF_ID: '1234567890-AbCdEfGh',
  API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
};
```

### 5. 自分をトレーナーとして登録する

1. スマホのLINEで `https://liff.line.me/（LIFF ID）` を開く → 「会員登録の確認中です」と出ます
2. スプレッドシートの **Pending** シートに自分の行ができているので、`lineUserId` をコピー
3. **Trainers** シートに `lineUserId` と `name`（ひとことの差出人として表示される名前）を追加し、Pending の自分の行は削除
4. もう一度開くと「トレーナー画面」になります。トレーナーが増えたときも同じ手順です。

### 6. LINE公式アカウントのリッチメニューにつなぐ

LINE Official Account Manager → リッチメニュー → アクションを「リンク」にして
`https://liff.line.me/（LIFF ID）` を設定します（ボタン名は「マイページ」「トレーニング記録」など）。

## 毎日の使い方（トレーナー）

1. **会員を追加**：会員一覧の「＋ 会員を追加」で、名前・コース・プラン・購入日・目標体重を登録
2. **LINEと連携**：会員さんにリッチメニューからマイページを開いてもらうと、一覧の上に「LINE連携の承認待ち」が出ます。その人がどの会員かを選んで「連携」
3. **レッスンのたびに**：会員を選んで
   - メニュー：日付とメニューを入れて保存（よく使うメニューはボタンで追加できます）。事前に入れておくと、会員さんには「次回のレッスン」として表示されます
   - 体重：体重・体脂肪率を記録
   - ひとこと：メッセージを送る
   - コース：ステップのチェック、プランの更新（回数券を買い足したら購入日を新しい日付にする）

**回数の数え方**：「レッスン回数に数える」にチェックしたメニューの数から自動で計算します。
- 回数券：購入日以降のレッスン数（有効期限は購入日から 5回券2か月・10回券3か月で自動入力）
- 月額コース：その月のレッスン数（毎月1日にリセット）
- 都度払い：これまでの合計

## 更新するとき

- **画面（mypage/ の中）**：ファイルを差し替えて公開し直すだけ
- **サーバー（Code.gs）**：Apps Script で貼り替えたあと、**デプロイ → デプロイを管理 → 編集 → バージョン「新バージョン」→ デプロイ**（URLは変わりません）

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | マイページ本体（会員画面・トレーナー画面） |
| `config.js` | LIFF ID とサーバーURLの設定 |
| `demo.js` | デモ表示用のサンプルデータ（本番では使われません） |
| `gas/Code.gs` | サーバー（Google Apps Script）。スプレッドシートに貼り付けて使います |
